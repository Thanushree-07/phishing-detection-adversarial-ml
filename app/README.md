# Running the demo app

This is the project's demo interface. It works with whatever has already been
trained/generated by the rest of the repo — it does not retrain anything itself.

## Setup

From the project root folder (the one containing `app/`, `data/`, `models/`,
`text_model/`, `attacks/`):

```bash
pip install -r app/requirements.txt
```

## Run

```bash
streamlit run app/app.py
```

This opens the app in your browser automatically (usually at
http://localhost:8501).

## What you need before running

The app reads already-trained models from disk. Make sure these exist first
(they're produced by scripts elsewhere in the repo):

- `models/baseline_logreg.pkl` and `models/baseline_gbt.pkl`
  → from running `models/train_baseline.py`
- `text_model/saved_model/tfidf_phishing_model.joblib` (and the hardened /
  adversarially trained versions, if you want the full results dashboard)
  → from running `text_model/tfidf_phishing_model.py` and
    `text_model/adversarial_training.py`

If any of these are missing, the corresponding part of the app will show a
clear "model not found" message instead of crashing — the rest of the app
still works.

## LLM classifier

The LLM tab works in two modes:

- **Real mode**: if `GROQ_API_KEY` is set in your `.env` file (project
  root), the app calls the real Gemini model, same as `attacks/llm_classifier.py`.
- **Offline fallback mode**: if no key is set, the app uses a simple
  keyword-based stand-in so the tab is still usable while the API key is
  being set up. The app clearly labels this mode whenever it's active, so
  results are never mistaken for the real LLM's output.

Once you have a working key, just add it to `.env`:

```
GROQ_API_KEY=your_key_here
```

No code changes needed — the app detects it automatically.

## Pages

1. **Live Classifier** — paste a URL, see predictions from all three model
   types (baseline, TF-IDF, LLM) side by side, plus the feature breakdown
   used by the baseline model.
2. **Evasion Attack Demo** — apply a character-level attack to a phishing URL
   and see whether the baseline and TF-IDF models still catch it.
3. **Prompt Injection Demo** — try 5 different ways of hiding an instruction
   inside a message, and compare the undefended vs. defended LLM classifier.
4. **Project Results** — displays the charts/tables already generated by
   `text_model/adversarial_evaluation.py` and the `attacks/` scripts, if
   present.
